# Estudo da Propriedade Display em CSS

> Um projeto prático desenvolvido para compreender e visualizar o comportamento dos principais valores da propriedade `display` no CSS.

---

## 🚀 Sobre o Projeto

Este repositório foi criado com o objetivo de servir como um guia visual e prático para o estudo da propriedade **`display`** do CSS. Através de exemplos comentados e estruturados, o projeto explora como diferentes valores afetam o fluxo de layout e o comportamento dos elementos HTML na página.

Os conceitos abordados incluem:
*   **`display: none`**: Oculta completamente o elemento da página (removendo-o do fluxo visual).
*   **`display: block`**: Ocupa toda a largura disponível e quebra a linha antes e depois do elemento.
*   **`display: inline`**: Ocupa apenas o espaço necessário para o seu conteúdo e não quebra linhas.
*   **`display: inline-block`**: Permite o comportamento em linha (`inline`), mas aceita propriedades de largura, altura, margens e preenchimentos (`block`).
*   **`display: flex`** (Flexbox): Um modelo de layout unidimensional poderoso para distribuição de espaço e alinhamento de itens.
